# Glossary

**Particle Points (PP)** — DustSwap's off-chain progression points balance. Not a token; no monetary value today. See [PP Rewards](../rewards/pp-rewards.md).

**Streak boost** — A bonus of +10% per consecutive daily check-in, capped at +300% on day 30, applied to most PP-earning actions. See [Streak Boost Explained](../rewards/streak-boost-explained.md).

**DustSweep** — The feature that sweeps small "dust" token balances into ETH, USDC, WETH, or USDT in one transaction. See [What is DustSweep?](../dustsweep/what-is-dustsweep.md).

**Permit2** — A Uniswap-built contract that lets you sign an off-chain approval message instead of sending an on-chain `approve` transaction per token. See [Sign & Sweep](../dustsweep/sign-and-sweep.md).

**EIP-7702** — An Ethereum standard that lets certain wallets temporarily act like smart contract accounts, enabling one-click batched approvals + sweeps. See [EIP-7702 Explained](../dustsweep/eip-7702-explained.md).

**EIP-5792** — A wallet standard for batching multiple calls (e.g. approve + sweep) into one user confirmation. See [One-Click Sweeps](../dustsweep/one-click-sweeps.md).

**TGE (Token Generation Event)** — A future event at which DustSwap plans to reward leaderboard standing. Not finalized or scheduled. See [Leaderboard Overview](../leaderboards/leaderboard-overview.md).

**Co-Founder Pass** — A planned (not live) NFT that would boost referral commission to 30%. See [Referral Rewards](../referrals/referral-rewards.md).

**Spin tickets** — A separate balance (3 granted per daily check-in, 1 spent per spin) used to play [Spin Rewards](../rewards/spin-rewards.md).
