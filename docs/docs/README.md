# Dustswap Documentation

Official documentation for Dustswap, DustSweep, rewards, quests, referrals, security, and ecosystem features.

Dustswap is a Base-network app combining a token swap experience (in partnership with OpenOcean) with DustSweep — a one-click dust-token cleanup tool — and a full rewards layer: Particle Points, daily check-ins with streak boosts, quests, referrals, and leaderboards.

## Where to start

- New to Dustswap? Start with [What is Dustswap](introduction/what-is-dustswap.md).
- Want to clean up small token balances? See [What is DustSweep](dustsweep/what-is-dustsweep.md) and [Quick Start](dustsweep/quick-start.md).
- Curious about earning rewards? See [PP Rewards](rewards/pp-rewards.md) and [Daily Check-In](rewards/daily-check-in.md).
- Looking for contract addresses? See [DustSweep Router](contracts/dustsweep-router.md).

## Important notes

- Dustswap currently runs on **Base mainnet** only.
- Particle Points (PP) have **no monetary value today** — see [Risk Disclosures](security/risk-disclosures.md).
- The user-facing swap and (upcoming) bridge experience is provided **in partnership with OpenOcean**.

> **User Safety Note**
> Dustswap only operates through `app.dustswap.wtf` and the official Discord. See [User Safety](security/user-safety.md) and [Official Links](introduction/official-links.md).
