# Referral Eligibility Rules

## Who can apply a referral code

Anyone who has **never had a referrer** can apply a referral code — including existing DustSwap users, not just brand-new accounts. Once applied, the referrer is permanent and cannot be changed.

## Who earns what

- **Signup bonus:** both the referrer and the new user receive **500 PP** when a code is applied.
- **Lifetime commission:** the referrer earns **20%** of the referee's eligible PP earnings, for the lifetime of the account relationship, single-level only (no pyramid — you don't earn from your invitees' invitees).
- Referral-type actions themselves (signup bonuses, commission payouts) are **not** eligible for further commission — this prevents recursive commission loops.

## Rules & limits

- One referrer per account, forever — cannot be changed later.
- Self-referral is blocked.
- A **Co-Founder Pass** boost to a 30% commission rate is **planned but not live** — see [Referral Rewards](referral-rewards.md).
