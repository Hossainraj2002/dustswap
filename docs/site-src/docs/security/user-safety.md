# User Safety

DustSwap documentation includes "User Safety Note" callouts throughout. This page summarizes the common scam patterns to watch for across the platform.

## Common scam patterns

- **Fake PP sales / pre-TGE allocations.** Particle Points have no monetary value today and cannot be bought or sold. Anyone offering this is running a scam. See [What are Particle Points?](../rewards/pp-rewards.md).
- **Fake referral links / phishing.** Only trust links in the form `app.dustswap.wtf/ref/...`. See [Referral FAQ](../referrals/referral-faq.md).
- **Fake "manual verification for a fee" for quests.** Quest verification is automatic (OAuth or on-chain) — DustSwap never charges for quest verification. See [Quest Verification & Claiming](../quests/verification.md).
- **Fake TGE claim sites / snapshots.** Leaderboard-based TGE rewards are planned but not finalized — any "claim your allocation" site before an official announcement is fake. See [Leaderboard Overview](../leaderboards/leaderboard-overview.md).
- **Fake Co-Founder/Founder Pass sales.** The Co-Founder Pass referral boost is planned but not live — there is currently nothing to buy.

## General rules

- DustSwap only operates through `app.dustswap.wtf` and the official Discord.
- DustSwap never DMs you first, and never asks you to "verify your wallet" by signing a message on an unfamiliar site.
- The only paid action in the rewards system is the optional **$1 streak recovery fee** (paid in ETH, inside the app) — see [Streak Recovery](../rewards/streak-recovery.md).
