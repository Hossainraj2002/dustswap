# Bridge

**Status: Coming soon — not live yet.**

DustSwap's app navigation shows a "Bridge — Soon" entry. The bridge feature is planned but not currently available.

## What's confirmed so far

- The bridge experience will be provided **in partnership with OpenOcean**, the same partner that powers [Swaps](swaps.md).
- The rewards system already has a bridge action ready: once live, bridging is planned to earn PP per token with a daily cap, similar to swaps and sweeps — exact figures will be published when the feature launches.

## What's not yet confirmed

To be confirmed before publication: supported networks/routes, fees, user flow, eligibility, and exact PP reward figures. This page will be expanded with full documentation at launch.

> **User Safety Note**
> Until DustSwap announces the Bridge as live through official channels (the app and the official Discord), any site or DM offering "DustSwap bridge access" is not official — do not connect your wallet to it.
